## dh_users — профиль пользователя

| Колонка | Тип | Что это | Зачем для работы | Можно убрать? |
|---|---|---|---|---|
| user_id | BIGINT PK | Telegram ID | Ключ всего: лента, мониторы, подписка, пуши. Обезличить нельзя — это идентификатор | Нет — нужен |
| first_name | TEXT, def 'Охотник' | Имя профиля TG | Отображение имени в приложении, текст боту («Имя, привет»), уведомление рефереру | Нужен. Вариант минимизации: хранить только для активных подписок, стирать после delete-me (уже стирается) |
| username | TEXT, def '' | @username TG | Обновляется в upsert; в UI нигде не отображается, нигде не отправляется | Дублирует first_name в назначении; username меняется в TG и часто пуст. ПРЕДЛОЖЕНИЕ: прекратить запись (оставить колонку пустой) — логика CASE WHEN EXCLUDED.username != '' уже позволяет. НЕ применено, ждёт подтверждения |
| trial_claimed | BOOLEAN | Брал ли триал | Антифрод (повторные триалы) | Нет — нужен |
| sub_until | TIMESTAMPTZ | Конец подписки PRO | Гейт всех платных функций | Нет — нужен |
| saved_ids | TEXT (JSON-массив) | Сохранённые лоты | Фича «сохранить лот» | Функционально нужен |
| claimed_ids | TEXT (JSON-массив) | Уже просмотренные/забранные лоты | Не дублировать лот в ленте | Функционально нужен |
| referred_by | BIGINT | Кто пригласил (числовой TG ID) | Реферальная программа, расчёт бонуса | Нужен, если партнёрка живёт |
| ref_rewarded | BOOLEAN | Бонус уже начислен | Однократность вознаграждения | Нужен с referred_by |
| ref_count | INT | Сколько приглашений | Отображение статистики партнёру | Нужен с referred_by |
| ref_days_earned | INT | Всего бонусных дней | Отображение статистики | Нужен с referred_by |
| ref_month / ref_month_days | TEXT/INT | Текущий месяц / дней за месяц | Месячный лимит бонусов MAX_REF_DAYS_PER_MONTH | Нужен с referred_by |
| created_at | TIMESTAMPTZ | Когда создан профиль | Используется и для минимизации: брошенные профили (>180 д без активности) удаляются фоном | Нет — нужен |
| signup_ip_hash | TEXT | Хэш IP при входе (антифрод фермы триалов/мультирефералов) | Только сравнение с более ранними хэшами | Обезличен (хэш). TTL уже есть: ежедневно стирается, если старше 30 дней (privacy-cleanup в monitor_scanner_loop) |
| trial_claimed_at | TIMESTAMPTZ | Когда выдан триал | Учёт триалов | Нужен для антифрод-отчётов |
| quiet_start / quiet_end | INT | Тихие часы пуши | Персональная настройка | Функционально нужен |
| terms_accepted_at | TIMESTAMPTZ | Факт согласия (152-ФЗ) | Доказательство согласия | Нет — нужен юридически |

## dh_lots — лоты (пользовательских данных НЕТ, но есть данные продавцов)

| Колонка | Зачем | ПД? |
|---|---|---|
| id, title, source, city, price, market, profit_rub, profit_pct, tags, description, url, created_at, gone, gone_at | Лента; TTL 14 дней (GIFTS меньше) | seller_name/seller_rating/seller_reviews — публичные данные витрины площадки (имя/ник продавца, рейтинг); приходят с площадок, не собираются нами. При delete-me НЕ удаляются — это не данные пользователя |

## Память процесса вне БД (не Postgres, стирается при рестарте/деплое)

- FallbackSessions.login_tokens / sessions: token -> (uid, expires, first_name, username). При delete-me все сессии пользователя убиваются (drop_sessions_for_uid).
