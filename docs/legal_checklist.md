### Что нужно для хранения в РФ (НЕ ВЫПОЛНЕНО, требует твоего подтверждения)
1. Уведомление Роскомнадзора об обработке ПД (форма 2015 г.) и отдельно о трансграничной передаче (ст. 12 152-ФЗ) — до запуска рекламной кампании.
2. Закон о данных (152-ФЗ, ст. 18 ч. 5): при первичном сборе данных — сначала запись в РФ, потом копия за рубеж. Практически: либо перенести БД в РФ-регион (Selectel/Timeweb/Yandex Cloud + managed Postgres), либо первичный сбор данных перепроектировать. Перенос данных НЕ выполняется без твоего подтверждения.
3. Трансграничная передача: уведомление РКН + оценка правомерности (для стран, не входящих в Конвенцию Совета Европы, отдельный список РКН). Уточнить у юриста применимость к мини-апп и текущему масштабу.
4. Внутренний пакет 152-ФЗ: приказ о политике обработки, перечень обрабатываемых данных, назначение ответственного за организацию обработки, журнал обращений субъектов.
5. Маркировка рекламы: договор с оператора рекламных данных (ОРД) для собственных креативов, разъяснение партнёрам про ERID (38-ФЗ, маркировка интернет-рекламы обязательна с 2022; ответственность усилена).
